# Aussie Online Games — Privacy Policy

Responsive, designed HTML privacy-policy page for GitHub Pages.

## Publish
1. Create a public GitHub repository.
2. Upload `index.html` to the root.
3. In Settings → Pages, select Deploy from a branch → main → /(root).
4. Use the published HTTPS URL in Google Play Console and link to it from inside the app.

## Verify before publication
Confirm Firebase Analytics and OneSignal SDK configuration, data retention, deletion workflows, consent requirements, and age targeting. The policy is a draft and must reflect actual app behavior.
